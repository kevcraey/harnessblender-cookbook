# Priority Rules

Inbox items are prioritized for processing based on urgency and context.

## Priority Levels

| Priority | Source | Rationale |
|----------|--------|-----------|
| 1 | Unanswered report questions | Previous session left decisions pending |
| 2 | Root `*.md` files (Inbox Zero) | User intentionally placed for processing |
| 3 | New/modified journal entries | Captured thoughts that need integration |

## Scoring Factors

- **Recency**: More recent items score higher within same priority tier
- **User-flagged**: Items explicitly tagged with `#urgent` or `#priority` get +1 tier
- **Staleness**: Items pending > 7 days get warning flag 🚩
