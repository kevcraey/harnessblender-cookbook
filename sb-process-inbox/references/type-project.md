# Type: Project

A collection of tasks or work achieving a specific goal.

## Indicators

- Contains outcome or goal language ("build", "create", "launch", "migrate")
- Spans multiple steps or phases
- Has defined end state

## Examples

- "Redesign website homepage"
- "Plan summer vacation"
- "Migrate database to PostgreSQL"

## Target Location

`4-tasks/` with `type/project` tag

## Frontmatter

```yaml
tags:
  - type/project
```
