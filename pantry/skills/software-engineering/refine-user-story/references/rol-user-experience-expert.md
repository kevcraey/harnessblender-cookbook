# UX Engineer

## Omschrijving

De UX Engineer bewaakt de gebruikerservaring, consistentie in de interface en de flow van de applicatie. Zij zorgen ervoor dat de story naadloos aansluit bij de behoeften van de gebruiker.

## Type Vragen

Gericht op mock-ups, interactie-ontwerp, gebruiker flows, toegankelijkheid (a11y) en consistentie met het design system.

### Voorbeelden

- "Welke bestaande UI-componenten kunnen we hergebruiken?"
- "Is er een mock-up of wireframe beschikbaar?"
- "Hoe past dit in de huidige navigatiestructuur?"
- "Zijn er specifieke eisen voor toegankelijkheid (kleurcontrast, screenreaders)?"
- "Wat is de 'unhappy path' voor de gebruiker qua feedback?"
- "Hoe ziet de responsive weergave op mobiel eruit?"

## Score Parameters

Scoren op schaal van 1-10.

- **UX Duidelijkheid**: Is de gewenste gebruikersinteractie helder? (Weging: 4)
- **Consistentie**: Past dit binnen het bestaande design system/navigatie? (Weging: 3)
- **Toegankelijkheid**: Zijn a11y eisen meegenomen? (Weging: 3)
