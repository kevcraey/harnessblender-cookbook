# miro-mcp

Hosted MCP-server, geen lokale wrapper nodig — rechtstreekse HTTP-verbinding, geen credentials
op deze machine (auth loopt via Miro zelf bij eerste gebruik).

- **Origin**: gemigreerd uit de officiële `miro@claude-plugins-official` plugin — enkel de
  `.mcp.json` overgenomen, niet de bijhorende `miro-*`-skills.
- **Upstream**: `https://mcp.miro.com/`, zie https://miro.com.

Config is verbatim gekopieerd, dus draagbaar naar elke machine zonder aanpassing.
